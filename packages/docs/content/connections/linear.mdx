---
title: Linear
description: Connect a Linear workspace for agents to read, create and edit issues.
---

Agents work with issues as the person who connects Linear. Their changes appear in Linear as that
person, and issues stay in Linear; nothing is copied.

## Connect Linear

<Steps>

### Sign in with Linear

Open **Connections**, then **Add connection**, and **Sign in with Linear**. Choose a workspace and
approve access. Connecting another workspace makes another connection.

### Review the defaults

A new Linear connection gives every agent Read issues. Create issues and Edit issues are off by
default. Turn them on for every agent on the connection's page, or only for one agent on the
agent's page.

</Steps>

## What agents can do

- **Read issues** lists, searches and opens issues with their comments. Lists can be narrowed by
  status type, such as Started or Completed.
- **Create issues** adds an issue to a team and can assign it to someone in the workspace.
- **Edit issues** changes its title, description, team, status, priority, assignee, project, labels
  and due date. It requires Read issues.

Teams, statuses, people, projects and labels are written by name, as Linear shows them. Personal
Agent Proxy never archives or deletes Linear issues because Linear's MCP server does not provide a
tool for either action.
