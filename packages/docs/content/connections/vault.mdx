---
title: Vault
description: Keep what your agents should know about you, and let them remember what they learn.
---

The vault is built in: what you want every agent to know about you, without connecting an outside
service. It is also your agents' memory: an agent you let edit it can keep what it learns, such as
how you like things done, so the next agent doesn't have to ask.

Each entry is a key, a type and a value, such as "Home", Address and the address written out. The
types are Text, Address, Phone number, Email, Link and Date. Agents read every entry as written.

<Steps>

### Add an entry

Open **Vault** in the sidebar and choose **Add entry**.

### Give agents access

The vault has two actions: **Read entries** and **Edit entries**, which also requires Read. Set them
on the agent's page, which can also make a setting the default for every agent.

</Steps>

## Agents and the vault

An agent that can read the vault is told to look there before asking you something about yourself.
One that can also edit it is told to save what would help next time as an entry, and to update an
entry when something has changed rather than add another. Every entry an agent reads, adds or edits
is in the activity log.
