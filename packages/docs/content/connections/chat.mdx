---
title: Chat
description: Let an agent read your threads with the built-in agents, and see and cancel the alerts set in them.
---

Chat is built in: your own threads on the **Chat** page, with every agent Personal Agent Proxy runs
for you there, and the alerts set in them, as something an agent can read. It is what lets you ask
about your threads in a thread: what is waiting for you, what was found in another one, which
alerts are set ([Chat with the built-in agent](/agents/chat#asking-about-your-other-threads)).

You have one of your own in every organization, once Chat has been used there. Nobody else sees
it, and it can't be shared, renamed or deleted: your chats are yours alone, and so is this.

An agent reads two things through it:

- **Threads**: each by its title, the agent it is with, where it stands (In progress, Waiting for
  you or Done), the sentence that says where it is, and when something was last said in it. Opened,
  a thread also has what was said in it, as its page shows it: what you said, what the agent
  answered and the alerts that came, never the calls the agent made. Each has a link to its page in
  Chat.
- **Alerts**: each by its title, when it comes or what it watches, what was noted for it, and the
  thread it was set in, which is where it comes.

Nothing is written to a thread through it. An agent that finds what you asked about in another
thread says so and links to that thread, and you go on with it there.

<Steps>

### Choose what agents can do

Open **Connections and permissions** in the sidebar, then **Chat**. It has three actions: **Read
threads**, **See alerts**, and **Cancel alerts**, which also requires See alerts.

Chat, the built-in agent, gets all three. Every other agent starts with none: a thread may say what
came from a connection that agent was never given, such as a summary of your mail. Turn an action
on for an agent on its **Permissions** tab, or off for Chat.

</Steps>

## Alerts in a thread

Whatever is set here, the agent of a thread is told of all your alerts, since it is the one that
set each of them, and cancels any of them when you ask, whichever thread it was set in. An alert is
set in a thread, by that thread's agent, and comes back to that thread.
