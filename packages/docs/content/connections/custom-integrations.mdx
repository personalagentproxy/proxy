---
title: Custom integrations
description: Learn how planned custom integrations will connect services that are not included yet.
---

Custom integrations are planned. They will let you set up services that are not built into
Personal Agent Proxy, so an agent can work with your tools through the same login, access controls
and activity log as the integrations included today.

## What you will be able to define

A custom integration will describe:

- the collections of records an agent can list and open;
- the fields each record contains;
- the actions that read, create, edit or delete records;
- commands an agent can run, and the action each command requires; and
- how Personal Agent Proxy connects to the service.

Each connected account will then have defaults for those actions, with per-agent overrides where
one agent needs different access. Allowed and denied requests will appear in the activity log just
like requests to Email, Granola and Information.

<Callout>
  Custom integrations are not available yet. For now, use the built-in integrations listed above.
</Callout>
