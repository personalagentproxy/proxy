---
title: Introduction
description: What Personal Agent Proxy is, and what you run to host it yourself.
---

Personal Agent Proxy holds the integrations and personal information an AI agent needs, so every
agent company does not have to rebuild them and you do not have to trust each one's security. You
connect your services and hand out agent logins; an agent signs in with one and works through what
it was given. Every request an agent makes is checked against its access and written to the activity
log, allowed or denied.

The connection guides explain the integrations available today: [Information](/connections/information)
for details stored in Personal Agent Proxy, [Email](/connections/email) for IMAP and SMTP mailboxes,
and [Granola](/connections/granola) for meeting notes and transcripts. [Custom integrations](/connections/custom-integrations)
explains what is planned for services that are not built in yet.

Personal Agent Proxy is open source, and you can run it on your own server.
[Self-hosting](/self-hosting) explains how it fits together, and
[Get started](/self-hosting/get-started) has it running in a few minutes with Docker Compose.
