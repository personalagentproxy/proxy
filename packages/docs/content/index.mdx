---
title: Introduction
description: What Personal Agent Proxy is, and what you run to host it yourself.
---

Personal Agent Proxy holds the integrations and personal information an AI agent needs, so every
agent company does not have to rebuild them and you do not have to trust each one's security. You
connect your services and hand out agent logins; an agent signs in with one and works through what
it was given. Successful connection actions, actions denied by the login's access settings, and
actions the service failed are written to the activity log. [Organizations](/organizations) let you
work with other people on one set of connections and agents.

On the home page, [quick actions](/quick-actions) find people, email and files, work with calendars,
write email, calculate, convert units and show balances or spending from the services you connect.

The connection guides explain the integrations available today: the [Vault](/connections/vault)
for what agents should know about you, [Email](/connections/email) for IMAP and SMTP mailboxes,
[Google](/connections/google) for Gmail, Calendar, Drive, Docs, Sheets, Slides and Contacts,
[Granola](/connections/granola) for meeting notes and transcripts, [Notion](/connections/notion)
for pages and databases, [Linear](/connections/linear) for issues,
[Cloudflare](/connections/cloudflare) for zones, DNS, Workers and the rest of an account,
[Exa](/connections/exa) or [Parallel](/connections/parallel) for searching and reading the web,
[Plaid](/connections/plaid) for bank balances and transactions, and
[PostgreSQL](/connections/postgres) or [MySQL](/connections/mysql) for a database's tables and
queries. [Custom MCP servers](/connections/custom-mcp) explains how to connect any other service
that has an MCP server, and allow its tools one by one.

Personal Agent Proxy is open source, and you can run it on your own server.
[Self-hosting](/self-hosting) explains how it fits together, and
[Get started](/self-hosting/get-started) has it running in a few minutes with Docker Compose.
