These tables are built from the server's own list of what it reads, so they always match the
version they are published with. An empty variable counts as unset. With Docker Compose, the
[compose file's settings](/self-hosting/get-started#settings) fill in most of them.

## Core

Proxy does not work without these, though it still starts, so that its errors can say what is
missing.

## The image

Read by the image's entrypoint, before the server starts.

| Variable          | Required / default | Description                                                                                                   |
| ----------------- | ------------------ | ------------------------------------------------------------------------------------------------------------- |
| `SKIP_MIGRATIONS` | Optional           | `true` starts the server without applying the database migrations first, for when they run as their own step. |
