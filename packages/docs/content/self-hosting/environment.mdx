[compose file's settings](/self-hosting/get-started#settings) fill in most of them.

## Core

The variables marked **Required** are needed for Personal Agent Proxy to work. The optional Core
variables turn on quick actions on the home page and the built-in agent on the Chat page.

<EnvTable group="Core" />

A member who connected their Claude account gets the Chat agent run on the Claude Agent SDK under
it, which runs Claude Code as a subprocess for each turn: a few hundred megabytes of memory while
the turn lasts, on top of the server's own. `CLAUDE_AGENT_SDK_TURNS` is how many such turns one
server runs at once, one unless you raise it; a server with little memory to spare can turn the
SDK off with `CLAUDE_AGENT_SDK=off`, and every conversation then runs on `OPENROUTER_KEY`.

## Observability

The api writes its log to stdout, one JSON object per line, which `docker compose logs api` shows.
These ship it to a [Loki](https://grafana.com/oss/loki/) as well, and its metrics to a Prometheus
or any other store taking OTLP, as hosted Personal Agent Proxy does; a self-hosted server needs
none of them.
